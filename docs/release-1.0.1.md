# v1.0.1 发布检查

检查日期：2026-11-09，Asia/Shanghai。本版为请求重投相关的补丁版本，源码和最终 CI 见 [v1.0.1 Release](https://github.com/W205614/Causelume/releases/tag/v1.0.1)。

## 修复与契约

- 服务停用后，同一操作者、同一 requestId 和相同内容的工单创建请求仍返回原工单，不追加时间线或重复建单；修改请求内容仍返回 409。停用服务拒绝新请求，其他账号不能借用原账号的 requestId 绕过该限制。
- 调查窗口输入先按数据库规则四舍五入到微秒，再校验、存储和比较。修复纳秒时间经 H2/PostgreSQL 持久化后，同一请求重投被误判为冲突的问题，同时覆盖旧版已经保存的请求。微秒窗口不同仍返回 409，规范化后长度为零的窗口返回 400。
- 同步应用版本、Docker 构建路径、验收脚本与存储命令示例。依赖、前端业务交互、生产配置和数据库 schema 均未改变，仍为 V9。

两个问题均先通过真实 HTTP 和隔离 H2 数据库复现，再修复。PostgreSQL 合同同时覆盖对应重投行为；上游故障测试使用不可用的隔离 Agent 地址，不调用模型供应商。
