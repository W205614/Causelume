# 单实例运维边界

## 已有部署

业务数据保存在 app 的 H2 文件卷。默认回环端口用于本机访问，调查服务和 Holmes 没有宿主发布端口。临时开发库、前端模拟模式和持久化实例的记录分开。账户与工具权限由后端检查，只有 checkout 演示服务提供受控故障注入。

## 面向其他使用范围前的条件

| 主题 | 当前措施 | 扩大使用范围前需完成 |
|---|---|---|
| 数据与恢复 | Flyway 版本迁移、单机命名卷、事务和乐观锁 | 为业务库及运行配置制定一致备份、保留周期、异地保存和恢复演练。磁盘损坏或删卷会丢失单机数据；定义可接受的数据丢失量和恢复时间。 |
| TLS 与代理 | 默认回环 HTTP；支持固定外部 HTTPS Origin 与 Secure 会话 | 由受控反代终止 TLS、限制直连、核验外部域名及证书、实测完整代理链。 |
| 认证与密钥 | BCrypt、HttpOnly/SameSite、服务端角色、独立内部令牌；模型密钥只给 Holmes | 多团队场景评估 SSO/MFA、密码与令牌轮换、账号禁用及会话撤销。用受控密钥服务替代开发用 .env。 |
| 负载与限流 | 单机登录限流、请求及结果上限、分页、任务容量限制 | 依真实流量验证延迟、容量、工作者饱和和拒绝行为；代理/NAT 共用来源时评估限流误伤。多实例需一致的配额。 |
| 观测与隐私 | 健康接口、工单和任务状态、失败代码及本地审计 | 采集告警、队列等待、错误率、磁盘和备份健康；定义敏感字段脱敏、日志访问和导出策略。审计库和业务数据共机，需单独考虑防篡改。 |
| 数据生命周期 | checkout 仅保留最近 50 次请求，持久化库保存工单及调查快照 | 依业务确定历史归档、删除授权、保留期限、容量阈值和隐私请求流程。长时间线按实际规模另行设计。 |
| 模型与工具 | 只读、请求级快照、结构化结果、失败终态 | 真实外部系统需要逐源授权、脱敏、数据出境/供应商评估、预算与使用提醒；质量要用带标注的故障样本评估。 |
| 扩容协调 | 单一文件库与单 worker；状态条件更新、截止时间收尾；未知付费结果不自动重试 | 多实例前先确立共享存储、认领租约、实例隔离和恢复归属；单机重启收尾不适用于并行实例。再决定是否迁移数据库或引入队列。 |
| 依赖与交付 | 固定主要镜像及 Holmes 发行版，CI 验证构建、业务链路与容器 | 维护依赖漏洞扫描、镜像来源、补丁时限、权限审查与升级回滚演练；当前功能测试不等于供应链审计。 |

## 升级检查

1. 记录目标项目、原提交、Compose 配置版本和镜像摘要，识别真正挂载的卷及 app 的数据库路径。对可能仍在调查的工单确认状态和维护窗口。
2. 停止本项目写入数据库的 app，保存完整静止的 data 目录；保护备份中的账户哈希与业务记录。用独立库验证其可读。维护真实模型配置时分开保存密钥。
3. 在隔离副本上按版本迁移，比较已有工单、证据、反馈和审计记录；旧数据缺少的采样/开始时间保留未知。
4. 经数据所有者确认后更新原部署；重新登录核对历史记录，验证低风险只读接口。付费调查、写入演示记录应单独获得授权。
