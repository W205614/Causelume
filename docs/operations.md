# 单机运维与上线边界

本地 H2/checkout 演示使用 compose.yaml；个人生产候选使用 compose.production.yaml、compose.observability.yaml 和 PostgreSQL。后者已完成隔离集成验证，真实云资源尚未接入。配置操作见 [生产接入手册](production-setup.md)，本轮证据见 [候选验收](personal-release.md)。

| 主题 | 候选已落实 | 真实接入或扩大范围前 |
|---|---|---|
| 数据与恢复 | PG18、独立运行/迁移账户、H2离线核对迁移、一致加密备份、独立库恢复校验 | 接通异地仓库；完整新主机恢复并计时证明RPO24h/RTO2h。配置保留周期后再确认清理。 |
| TLS与代理 | Caddy HTTPS入口、内部端口隔离、Secure会话、固定Origin | 真实域名/证书/防火墙和代理链验收。 |
| 身份与凭据 | BCrypt、角色、会话撤销、强制TOTP、防重放及单次恢复码、受限文件 | 轮换聊天中出现过的模型密钥；独立保管MFA加密密钥及恢复密码。多人/团队版再评估SSO。 |
| 告警与通知 | Alertmanager机器认证、标签/环境映射、过程去重、恢复、维护静默、事务Outbox、明确投递状态 | 配置真实SMTP与收件人，验证实际送达和服务商限额。 |
| 观测与隐私 | 服务范围、查询网关、同窗口快照、来源/缺失/截断记录、日志字段脱敏、受限导出 | 接入项目网络/日志卷并演练故障；评估供应商隐私及日志保留规则。审计与业务同库，没有防篡改归档。 |
| 平台监控 | 请求/连接池/队列/失败/应用磁盘指标及规则、宿主磁盘阈值、机外运行与备份心跳入口 | 在机外创建检查并演练整机断联与备份停止；其他主机分区按需增加检查。 |
| 负载与限流 | 登录限流、请求和结果上限、稳定分页、单worker队列和查询边界 | 依据首批项目采集量实测CPU/内存/IO、延迟和磁盘增长，检查NAT限流误伤。 |
| 数据生命周期 | 服务停用保留历史、分页时间线、复盘/改进项、清理预览；观测存储7天保留 | 明确保留与备份政策后另行确认业务历史删除。当前没有自动删除业务历史。 |
| 模型与工具 | 人工发起、冻结只读证据、结构化结果、每日预留、未知费用不自动重试或释放 | 新密钥和授权后真实调用；供应商用量/账单仍需核对，预算预留不是硬账单上限。 |
| 依赖与交付 | 固定基础镜像摘要、CI依赖/秘密/应用镜像扫描、发布清单、备份后升级 | 按扫描报告处理漏洞、验证补丁及数据库回退；功能通过不等于供应链检查通过。 |
| 扩容协调 | 单实例、单worker、条件终态与超时恢复 | 多实例前需任务认领/租约/恢复归属和共享配额；目前不支持并行部署两个业务实例。 |

H2演示升级仍先停止写入、复制静态库并验证副本。生产PG升级按发布脚本先备份；数据库已停或卷不匹配时脚本拒绝继续。数据库迁移后的回退使用经过核对的兼容应用版本或完整恢复集。任何破坏性数据清理另行确认。
